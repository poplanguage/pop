# Core and Portable Library Catalog

## Reading the catalog

Every row is a placement contract, not an API completeness claim. `Pure` means
the primary implementation can be Pop source; `PLRI` means some operation needs
the runtime interface. Cost statements are intended contracts until benchmarks
stabilize a numeric budget.

## Values, numerics, and sequences

| Root | Tier/status/phase | Scope and public concepts | Dependencies, portability, cost, security, extension, exclusions |
| --- | --- | --- | --- |
| `Math` | standard; `prototype` integer core; phase 1 | implemented `Int` functions `min`, `max`, `abs`, `gcd`, `sign`, `lcm`, `coprime`, optional-bound `clamp`, logarithmic checked `power`, `floorDivide`, and `floorRemainder`; planned float/decimal operations, `Math.Big`, `Math.Rational`, and `Math.Complex` | Current functions are ordinary pure Pop with checked `Int` semantics, no allocation, dispatch, suspension, or native transition; ADR 0111 fixes invalid-bound, negative-exponent, and floor-division policies; broader numeric protocols, big-value allocation, and floating-point edge contracts remain separate work; no random/statistics/linear algebra |
| `Random` | standard; deterministic state, bounded integer/unit-float/probability sampling, byte fill, and in-place shuffle implemented; specialized distributions and entropy seeding planned; phase 1 | Park-Miller `State`; `seed`, `next`, unbiased `nextInt`, unit `nextFloat`, `chance`, unbiased `fill`, unbiased `shuffle`; later specialized distributions and explicit nondeterministic seeding | ADR 0126 freezes the MINSTD stream, normalizes every UInt32 seed, uses explicit mutable state, and rejects global state; ADR 0127 shares rejection sampling across bounded operations and covers the complete signed-Int width check; ordinary Pop plus an explicit entropy capability only for later nondeterministic seeding; cryptographic randomness belongs to `Crypto` |
| `Guid` | standard; canonical value/text/bytes, named nil/version-four inspection, and explicit-random-bytes version-four generation implemented; general version cases and constructors planned; phase 1 | `Guid.Value`; `parse`, `format`, `fromBytes`, `toBytes`, `isNil`, `isVersion4`, `newVersion4` | ADR 0134 replaces the dormant prelude placeholder with four exact network-order words, canonical `8-4-4-4-12` text, exact 16-byte interchange, named nil/version-four predicates, and exactly 16 caller-supplied random bytes; ordinary record/text/byte allocations are stated; later public-enum metadata must precede general named cases, `Crypto` supplies secure entropy acquisition, and timestamp/name/hash-specific constructors remain focused work |
| `Version` | standard; bounded semantic value and single-requirement matching implemented; broader tooling policy planned; phase 1 | `Version.Value`; `parse`, `format`, `compare`, `matches`; later typed package requirement composition belongs to tooling | ADR 0131 fixes complete Semantic Versioning 2.0.0 syntax, a 1,024-byte input bound, owned prerelease/build text, canonical precedence, and exact/comparison/caret/tilde requirements in ordinary pure Pop; package selection, range composition, and prerelease opt-in policy stay in tooling |
| `Uri` | standard; bounded owned ASCII references, formatting, component percent coding, and hierarchical resolution implemented; views/query/IRI policy planned; phase 1 | `Uri.Value`; `parse`, `format`, `percentEncode`, `percentDecode`, `resolve`; later URI views and `Uri.Query` | ADR 0133 limits references/components to 4,096 bytes, preserves optional empty authority/query/fragment, lowercases only schemes, validates percent escapes/UTF-8, and resolves lexical dot segments in ordinary pure Pop; IDNA, host/port parsing, scheme trust/dispatch, DNS, and HTTP transport remain explicit later APIs |
| `Mime` | standard; bounded owned values, parameters, formatting, lookup, and identity matching implemented; registry lookup planned; phase 1 | `Mime.Value`, ordered `Mime.Parameter`; `parse`, `format`, `parameter`, exact/`type/*`/`*/*` `matches`; later generated extension lookup | ADR 0132 limits complete input to 1,024 bytes and 32 ordered parameters, canonicalizes ASCII token identities/names, decodes bounded quoted values, rejects duplicates, and uses ordinary pure Pop; registry data needs a versioned generated-data contract; content sniffing is explicit and belongs to format/media Packages |
| `Sequence` | standard; `prototype`; phase 1 | implemented lazy `map`, `filter`, `take`, `drop`, `takeWhile`, `dropWhile`, `concat`, `append`, `prepend`, `scan`; eager `fold`, `reduceOr`, `any`, `all`, `count`, `isEmpty`, `first`, `last`, `firstOr`, `lastOr`, `elementAtOr`, `findOr`, `findLastOr`, `indexOr`, `indexLastOr`, `each`, `none`, `countWhere`; checked integer `sum`, `product`, `minOr`, `maxOr`, `sumBy`, `productBy`, `minByOr`, `maxByOr`; materializing `collect`, stable `sort`/`sortBy`, `reverse`, `containsBy`, `equalsBy`; planned zip/window/chunk/group and later no-fallback terminal families | Pure Pop + compiler iteration protocol; terminal operations allocate no storage of their own except documented materializing algorithms; each current lazy adapter allocates one typed state object and never materializes input; ADR 0128 uses stable insertion order and closed pure callbacks; ADR 0130 returns exact `Iteration<T>` from `first`/`last`; nonpositive bounds normalize to zero; indexes are one-based; traversal, callback counts, and short-circuit order are fixed; numeric aggregates are currently exact `Int` operations; parallelism belongs to `Task`; no `Iter` alias |

Primitive values, tuples, result packs, records, optional `T?` values, `Result`,
equality, ordering, hashing, copying, and conversion are language/prelude
contracts rather than namespace families. Collections use direct types
(`Array`, `List`, `Map`, `Set`, `Queue`, immutable variants) and `Sequence`
algorithms. This avoids a duplicate nominal `Option<T>` wrapper and a ceremonial
`Collection` root.

The initial `List<T>` contract is the one-based growable sequence from ADR 0053:
`create`, `withCapacity`, `add`, `length`, optional indexing, checked `get`, and
checked replacement. Its capacity policy is private; arrays remain fixed.

| `Bytes` | standard; portable foundation implemented; phase 1 | immutable owned `Bytes`; view inspection/search and endian reads; distinct reusable `Bytes.Buffer` and endian writes; checked UTF-8; canonical hexadecimal, base64, and base32; checked equal-length bitwise AND/OR/XOR and bytewise NOT | ADR 0097 defines immutable views; ADR 0113 keeps reads allocation-free; ADR 0117 keeps mutable storage distinct; ADR 0118 validates UTF-8; ADR 0119 implements hexadecimal; ADRs 0120 and 0121 strictly reject codec aliases, malformed padding, and nonzero unused bits; ADR 0122 returns absence rather than truncating mismatched bitwise inputs; indexes are one-based; advanced decoders expose sizing limits; cryptographic operations belong to `Crypto` |

INI remains an official compatibility Package `Pop.Ini` only when a concrete
ecosystem need accepts its weak duplicate/key/type semantics. It is not a
reserved root in the standard catalog.

## Locale, resources, and time

| Root | Tier/status/phase | Scope and public concepts | Dependencies, portability, cost, security, extension, exclusions |
| --- | --- | --- | --- |
| `Locale` | standard/platform; planned; phase 2 | `Locale.Tag`, negotiation, collation, number/currency/unit/date formatting, calendars, time zones, plural/select rules; `Locale.Message` | Unicode/Time/Resource; CLDR/tz data generated and versioned; formatters reusable; no ambient current locale; platform locale discovery is explicit; custom data packs are typed/versioned |
| `Resource` | standard/tooling; planned; phase 2 | typed packaged text/binary assets, locale bundles, fallback, generated keys, `load`, `text`, `bytes` | Package metadata/Codec/Locale/Io; compile-time key validation; cache policy explicit; untrusted override limits; never `Table<String, String>` or runtime name lookup |
| `Time` | standard/platform; canonical exact `Duration`, deterministic test clock, and bounded civil `Date` implemented; host clocks/zones/timers planned; phase 2 | implemented `Duration`, bounded monotonic `Instant`, `Deadline`, explicit mutable `TestClock`, and proleptic-Gregorian `Date`; exact duration construction/comparison/inspection, validated instant/clock construction, snapshots, checked advancement, deadline construction/expiry, date validation/leap/month-length/comparison; later `DateTime`, `Zone`, host `Clock`, sleep/timers | ADR 0136 defines canonical duration units; ADR 0137 bounds test instants and rejects backward/overflowing movement without mutation; ADR 0138 bounds civil dates to years 1 through 9,999 without clock/zone/locale authority; later PLRI clocks/timers keep monotonic and wall clocks distinct and document scheduling; locale formatting belongs to `Locale`; cron/job scheduling is official |

Localization YAML uses `resources/<tag>/<domain>.yaml`. The resource compiler
validates one default-locale schema, parameter types, plural/select coverage,
fallbacks, interpolation escaping, duplicate/missing keys, and rich-fragment
types. It generates nominal keys and parameter records. Runtime loaders accept
those identities, not strings; cache and override capabilities are explicit.
